# BUG-001: Product images are identical across all products

**Severity:** Medium
**Environment:** Chrome, saucedemo.com, logged in as problem_user

## Steps to Reproduce
1. Log in to saucedemo.com as problem_user / secret_sauce
2. View the product listing page (Products)
3. Observe the image for each product in the grid

## Expected Result
Each product displays its own distinct image matching the product name/description

## Actual Result
All products display the identical image, regardless of product name or type

## Impact
Users cannot visually distinguish between products, which would affect purchasing
decisions in a real e-commerce context
