# BUG-002: Sort dropdown does not reorder products

**Severity:** High
**Environment:** Chrome, saucedemo.com, logged in as problem_user

## Steps to Reproduce
1. Log in to saucedemo.com as problem_user / secret_sauce
2. On the product listing page, open the sort dropdown
3. Select "Name (Z to A)"
4. Observe product order
5. Repeat selecting "Price (low to high)" or "Price (high to low)"

## Expected Result
Product list reorders according to the selected sort option

## Actual Result
Product order does not change regardless of which sort option is selected

## Impact
Core browsing/filtering functionality is broken — users cannot rely on sort to
find products by name or price
